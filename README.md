# Task Tracker (Görev Takip Sistemi)

ASP.NET Core Razor Pages ve SQLite kullanılarak geliştirilmiş, modern ve kullanıcı dostu bir görev takip sistemi. Kullanıcıların günlük işlerini organize etmelerine, çalışma sürelerini takip etmelerine ve verimliliklerini artırmalarına yardımcı olur.

✨ Özellikler
  - Görev Yönetimi: Görev ekleme, düzenleme ve silme işlemleri.
  - Durum Takibi: "Tamamlandı" ve "Devam Ediyor" statüleri ile işlerin takibi.
  - Otomatik Süre Hesaplama: Başlangıç ve bitiş zamanlarına göre çalışma süresinin otomatik hesaplanması.
  - Modern Arayüz: Bootstrap ile geliştirilmiş, responsive ve göz yormayan tasarım.
  - Veri Yönetimi: SQLite ile hafif ve hızlı veri depolama.

🛠 Kullanılan Teknolojiler
  - Backend: ASP.NET Core 10 (Razor Pages)
  - Database: SQLite & Entity Framework Core
  - Frontend: Bootstrap 5, CSS3, HTML5
  - IDE: Visual Studio 2026

🚀 Kurulum
  1. Projeyi klonlayın:
    git clone https://github.com/gatilgan/TaskTracker.git
  2. appsettings.Example.json dosyasını kopyalayıp adını appsettings.json olarak değiştirin.
  3. Terminalde veritabanı güncellemelerini uygulayın:
     dotnet ef database update
  4. Projeyi çalıştırın.

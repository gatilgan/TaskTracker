# Task Tracker (Görev Takip Sistemi)

Bu proje, günlük görevlerinizi yönetmek ve süre takibi yapmak için geliştirilmiş bir .NET Razor Pages uygulamasıdır.

## 🛠 Kurulum ve Çalıştırma

1. Projeyi bilgisayarınıza indirin (Clone).
2. `appsettings.Example.json` dosyasının adını `appsettings.json` olarak değiştirin.
3. Veritabanı bağlantı ayarlarını (`ConnectionStrings`) kendi ortamınıza göre düzenleyin.
4. Terminalde `dotnet ef database update` komutunu çalıştırarak veritabanı tablolarını oluşturun.
5. Projeyi çalıştırın.
